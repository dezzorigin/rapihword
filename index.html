Fitur inti

Yang dikerjakan RapihWord di dalam file Anda.

Mengedit DOCX asli, bukan membangun ulang

RapihWord memodifikasi OOXML di dalam file Word. Tabel, gambar, hyperlink, catatan kaki, dan isi tulisan tetap di tempatnya.

  • Format diterapkan pada run & paragraf
  • File asli selalu disimpan
  • Hasil bisa dibuka dan diedit di Word

Pemeriksa yang menjelaskan, bukan menghakimi

Setiap temuan menyebut paragraf, nilai yang ditemukan, nilai yang diharapkan, dan rekomendasi perbaikannya.

  • Konsistensi font & ukuran teks
  • Margin, spasi, indentasi, perataan
  • Heading, halaman kosong, keterangan gambar

Section Word untuk penomoran halaman

Cover tanpa nomor, bagian awal Romawi, bagian isi Arab — dibuat sebagai section break dan field PAGE yang nyata.

  • Posisi nomor bawah/tengah/kanan
  • Restart nomor di bagian isi
  • Dapat diperiksa di Word

Daftar isi berupa field TOC

Heading dideteksi dari style, outline level, dan pola “BAB”. RapihWord menyisipkan field TOC yang bisa diperbarui di Word.

  • Kedalaman heading dapat diatur
  • Memberi tahu jika heading tidak ditemukan
  • Tidak menjanjikan pagination palsu

Batasan

RapihWord tidak berpura-pura menjadi Microsoft Word.

  • Preview adalah render struktural, bukan mesin layout Word. Pagination dan nomor halaman TOC bersifat estimasi sampai Word memperbarui field-nya. Tabel kompleks, text box, dan shape ditampilkan sederhana.
  • Format DOCX diubah langsung di OOXML.
  • Field TOC dan PAGE dibuat nyata.
  • File asli disimpan untuk pembatalan.
Keamanan & privasi

Dokumen Anda bukan bahan bakar model AI.

RapihWord menyimpan file hanya untuk kebutuhan pemrosesan dan riwayat Anda. Tidak ada penggunaan isi dokumen untuk pelatihan, tidak ada URL penyimpanan yang diekspos.

Validasi file sebenarnya

Signature ZIP, struktur OOXML, dan guard dekompresi — bukan hanya ekstensi.

Kepemilikan ketat

Setiap endpoint memeriksa pemilik dokumen. File disimpan dengan nama UUID internal.

Hapus kapan saja

Hapus dokumen dari riwayat beserta file asli dan hasil pemrosesannya.

Tanpa data palsu

Fitur yang belum akurat dijelaskan batasannya. Tidak ada formatting dekoratif.
